Object types to export

By default the types that have objects tagged “Include in the export” are preselected and their tagged objects are exported. Use “All objects” per type (or “Select all”) to include every object, even the not-tagged ones — or “Tagged only” to select every object type filter in the “Tagged only” scope (tagged objects of every type).

The export contains the selected object types from every firewall in the database — the destination receives all matching objects, not only its own imported configuration.

No objects will be exported with the current selection — tag objects on the object list page (“Include in the export”) or switch a type to “All objects”.
